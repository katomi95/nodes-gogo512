# 午後五時十二分 — 名前のないもの

ブラウザだけで動く短編アドベンチャー。
画面にあるのは、単語と、短い文と、ノードと、ノードを結ぶ線だけです。

絵を用意できないから文字なのではなく、
絵にした瞬間に意味が狭まってしまうものを扱うため、意図的に絵を使っていません。

---

## 動かす

`index.html` をブラウザで開くだけです。サーバーは要りません。
GitHub Pages にリポジトリごと置けば、そのまま公開できます（ビルド不要）。

進行状況は `localStorage` に自動保存されます。リロードしても続きから遊べます。

## 触りかた

**接続と重ねは、まったく別の操作です。**

| | 接続（線を引く） | 重ねる（乗せる） |
|---|---|---|
| 問い | この二つの**あいだ**に、何が起きるか | この二つは、**実は同じもの**ではないか |
| やりかた | 押す → もう一つ押す | 掴んで、相手の上ではなす |
| 線 | **残る**（あとから切れる） | **残らない** |
| 色 | 寒色（青） | 暖色（琥珀） |
| 操作中の表示 | 選んだ言葉の上に「接続 ／ つぎに押した言葉と、線で結ぶ」 | 指先に「重ねる ／ はなす（線は残らない）」 |
| 相手の見え方 | すでに繋がっている言葉が青くなり、末尾に「—」が付く | 乗せられる言葉が琥珀色に光る |
| 音 | 澄んだ高音 | 低くこもった二音 |

**置きかたを取り違えると、盤のほうから教えます。**
重ねにしか答えのない組を結ぼうとすると、線を引かずにこう返ります。

> 並べただけでは、何も起きない。……重ねてみたら、どうだろう。

逆も同じです。だから「組み合わせが外れた」と「操作が違った」を取り違えずに済みます。

その他の操作：

| 操作 | やること |
|---|---|
| ひらく | **点線で囲まれた言葉**は、押すだけでひらく。組み合わせなくてよい（詩人の心・神様など）。ひらくと囲みは消える。 |
| 切断 | 線を押す。粒になって消える。意味が変わることがある。 |
| 消す | 言葉を選ぶと下に「消す」が出る。消したことは、残る。 |
| 移動 | 掴んで動かす。何もない所を掴むと盤ごと動く。 |

正解を探す遊びではありません。
組み合わせが成立しなかったときも、たいてい何かは返ってきます。

音は既定でOFF。右上の「音」で入ります（音声ファイルは使わず、Web Audio で低いドローンと雨を合成しています）。

## ファイル構成

```
index.html
css/style.css
js/audio.js        環境音（ファイル不要の合成音）
js/game.js         エンジン。物理・操作・章進行・セーブ
js/data/nodes.js   ← 言葉の一覧
js/data/recipes.js ← 組み合わせ・すれ違いの案内
js/data/story.js   ← 章の進行・削除の特別扱い・エンディング
```

**シナリオを足すときは `js/data/` の3つだけ触れば済みます。**
`game.js` は触らなくて構いません。

### 言葉を1つ足す

`js/data/nodes.js`

```js
{ id: 'kasa2', label: '置いてきた傘', size: 'sm', uneasy: true },
```

| 項目 | 意味 |
|---|---|
| `id` | 内部ID。レシピから参照する |
| `label` | 画面に出る文字 |
| `size` | `sm` / `md`(既定) / `lg` / `core` |
| `start` | 開始時から盤面にある |
| `uneasy` | 不穏な章で文字が細かく揺れる |
| `keep` | 終盤の収束でも消えずに残る |
| `nodelete` | 消せない |
| `inspect` | **押すだけでひらく**。画面では点線の囲みが自動で付き、ひらくと外れる |

### 組み合わせを足す

`js/data/recipes.js`

```js
// 接続：線で結ぶ（線が残る）— 「あいだに何が起きるか」
['ame', 'kasa2', 'nurete', '結局、意味がなかった。'],

// 重ねる：乗せる（線は残らない）— 「実は同じものでは」
['ai', 'shuuchaku', 'kubetsu'],

// 切断：この線を切ると意味が変わる
['watashi', 'ie', 'kaerenai', '', { relabel: [['ie', '家だったもの']] }],

// ノードは生まれないが、何かは返ってくる
['kamisama', 'ame', '降らせたのか、降っただけなのか。'],
```

第5要素の効果オブジェクトは `{ relabel: [[id,'新しい文字']], flag: 'フラグ名', remove: ['id'] }`。

**同じ二語を `connect` と `overlay` の両方に、別の結果で書けます。**
片方にしか書かれていない組を逆の操作で試したときだけ `crossHints` が案内を出すので、
両方書いた組では案内は出ず、それぞれの結果がそのまま出ます。

案内の文面は `recipes.js` の `crossHints` にあります。増やしても構いません。

### 章と変化を足す

`js/data/story.js` の `events` に条件を書きます。

```js
{
  id: 'act3',
  act: 3,
  when: S => S.ever('gogo512') && S.ever('ienakatta'),
  text: '——見覚えのない言葉が、いつのまにか盤の上にある。',
  spawn: ['kamisama'],
  relabel: [['ame', '雨だったと思う']]
}
```

`when` に渡ってくるもの： `S.act` / `S.has(id)` / `S.ever(id)` / `S.flag(名)` / `S.countAny([id,...])`

`collapse: true` を付けた章で終盤の収束（多くのノードが消える）が起きます。

### 削除の特別扱い

`js/data/story.js` の `deletions`。

```js
kamisama: {
  text: '神様に繋がっていた線は、すべて「偶然」に繋ぎ直された。',
  rewireTo: 'guuzen'
},
uso: { text: '消した。', respawn: { delay: 2600, text: '消えなかった。' } },
watashi: { blocked: true, text: '——誰が、消すのか。' }
```

### エンディング

`js/data/recipes.js` の `endings` に「終盤に成立する2つの組み合わせ」を書き、
`js/data/story.js` の `endings` に本文を書きます。
`relabelCore` を付けると、暗転前に中央のノードが書き換わります。

### 手詰まりについて

盤上の言葉だけではもう新しい言葉も変化も引き出せなくなると、画面上部に
「——これ以上、新しい言葉は出てこない。」と出ます。
そのまま放っておくと、しばらくして終盤（収束）へ移り、必ずどれかのエンディングへ行けます。
言葉を消しすぎて詰む、ということは起きません。
